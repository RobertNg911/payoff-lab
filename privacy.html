Privacy Policy

Effective October 29, 2026

This policy covers two things run by the owner of the Payoff Lab YouTube channel (“we”, “us”):

  • Payoff Lab Uploader (“the app”), a command-line tool that uploads and publishes Payoff Lab videos through the YouTube Data API;
  • this website.

Watching Payoff Lab videos on YouTube is covered by YouTube's own terms and Google's privacy policy, not by this page.

1. Who uses the app

The app runs only on the channel owner's own computer. It is not offered to the public, and the only Google account that signs in to it is the account that manages the Payoff Lab channel. It has no server: nothing it handles is sent to us or to anyone other than Google.

2. Google user data the app accesses

The app uses the YouTube Data API with these permissions (OAuth scopes):

ScopeWhat the app uses it for
youtube.uploadUploading a video file with its title, description and tags, and setting its thumbnail.
youtube.force-sslReading the signed-in channel's ID and name; uploading English captions; reading a video's processing and privacy status; changing a video from private to public or scheduling it, when the owner asks.

The app reads only: the signed-in channel's ID and name, and the status and details of videos the app itself uploaded. It does not read subscribers, comments, watch history, analytics, email, contacts or any other data, and it does not delete anything.

3. How the data is stored

  • Sign-in token. Google's OAuth access and refresh token is saved in one file on the owner's computer (~/.config/game-theory-channel/token.json), readable only by the owner's user account (file mode 600). It is never printed, logged, committed to source control or sent anywhere except to Google.
  • Channel ID and name. Saved next to the token, and used to refuse uploads to any channel other than Payoff Lab.
  • Upload records. For each uploaded video, the app saves its YouTube video ID, link, channel ID, upload time and a checksum of the video file, so the same video is never uploaded twice.

All of this stays on the owner's computer until the owner deletes it.

4. Use and sharing

Google user data is used only to perform the actions listed in section 2, at the owner's request. We do not sell it, share it, transfer it to third parties, use it for advertising, or use it to develop, improve or train artificial intelligence or machine learning models.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. YouTube API Services

The app uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

6. Revoking access and deleting data

  • Revoke the app's access at any time at myaccount.google.com/permissions or Google security settings. After that, the saved token no longer works.
  • Delete the folder ~/.config/game-theory-channel/ to remove the token and the saved channel details from the computer.
  • Uploaded videos are managed in YouTube Studio like any other video.

7. This website

This website has no cookies, no analytics, no advertising, no forms and no sign-in. It is a set of static pages hosted on GitHub Pages. GitHub may record visitors' IP addresses in its server logs for security; see the GitHub Privacy Statement. The embedded links to YouTube take you to YouTube, where YouTube's terms apply.

8. Children

The app is used only by the channel owner. Payoff Lab videos are not made for children, and we do not knowingly collect personal information from children.

9. Changes

If this policy changes, the new version will be posted on this page with a new effective date. If the app ever starts accessing more Google user data, this page will be updated first.
